# Weather assets

Background photographs used by the city weather page:

- `rain-window.jpg`: rain / storm backdrop (raindrops on glass)
- `clear.jpg`: clear / sunny backdrop
- `clouds.jpg`: cloudy / mist / fallback backdrop (overcast sky)
- `snow.jpg`: snow backdrop

Icons in `outline/` are Lucide line icons plus local silhouettes used as CSS masks:

- `outline/rain-icon.png`: rain / thunderstorm icon (user-provided silhouette)
- `outline/cloud-reference.png`: cloudy icon silhouette
- other `outline/*.svg`: sun, snow, fog, umbrella, thermometer
